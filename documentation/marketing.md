- PROCESS:

Sellers bid for a product key word bidding is maxCPC, let's say maxCPC = 0.2
CPC (Cost per click)

When a customer clicks on your add, Shopee will charge you 0.2 or less (0.15, 0.1, etc.) depending on the auction 

how to choose maxCPC ?

SENARIO 1:

why not set maxCPC to the minimum possible, example maxcpc = 0.001?

Shopee ads to rank your prouct among all sellers they use bedding 

rank = bedding_price * quality_score

Let's fix quality score for all sellers to simplify.

seller | beddin price | quality score
--- | --- | --- |
A | 0.1 | 90 |
B | 0.15 | 90 |
... | ... | ... |
LLMCOREAI | 0.0001 | 90 |

In this scenario llmcoreai will get the lowest rank and won't appear to customers, 

It will get 0 clicks, therefore 0 sells, ad cost will be 0 yet no sells at all, this is not the objective.

SENARIO 2:

Why not set maxCPC to the maximum value possible, example : maxCPC = 0.35 ?

The problem is nobody knows what is the maximum value possible. To simplify let's estimate it to 0.35.

seller | beddin price | quality score
--- | --- | --- |
A | 0.1 | 90 |
B | 0.15 | 90 |
... | ... | ... |
LLMCOREAI | 0.35 | 90 |

In this scenario llmcoreai will indeed get the highest cost and therefore the maximum clicks and possibly a lot of sales
yet the cost this time is very big ad cost = number_of_clicks * maxCPC

LLMCOREAI was able to do same performance with only maxCPC = 0.15, lost cost is about 0.20, that is too much.

The real problem with not setting maxCPC to maximum value is that there is a limited ad budget for every product, 
if it 0.15 SGD, then this is the maximum value you can pay for advertising this product. 

So what is the best method to set maxCPC ?
METHOD 1:

Best strategy is to set maxCPC to a relatively low value and adjust it accordingly per iteration 

EXAMPLE : 
ITER 1 : 
Set : maxCPC = 0.05 SGD  Observation : no impressions, no clicks 
ITER 2 : 
Set : maxCPC = 0.01 SGD Observation : low impression, no clicks 
ITER 3 : 
set maxCPC = 0.02 SGD Observation : a lot of impressions, good number of clicks 
ITER 4:
set maxCPC = 0.025 SGD Obesrvation : more impressions, same number of clicks 

CONCLUSION : best maxCPC is 0.02

METHOD 2: 
Shopee allows you to Set maxCPC to be adjusted automatically:

advantages | disadvantages |
--- | --- |
max impressions | Pay more than necessary|
no manual tuning | Less controle|

the next most important question is : 

How much clicks my product needs to make 1 sale ? 

this is called conversion rate CR, a good starting point is 5%
5% means in every 100 clicks you get 5 sales --which means -- to get one sale you need 1/0.05 = 20 clicks

FORMULA sales = clicks * CR

advertising cost that should be invested is : 20 * maxCPC = 20 * 0.2 = 4 SGD credits to get one sale.


REAL world application : 

Given a product X
Given that CR for this product is 5%
To get one sale you need 
1/0.05 = 20 clicks 

Determine optimized maxCPC, let's say maxCPC = 0.15 credits 

ad cost = clicks * maxCPC = 20 * 0.15 = 3 credits = 3 SGD 

CONCLUSION : to make 1 sale of product X you need 3 SGD ad cost.
